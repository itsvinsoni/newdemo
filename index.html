Motion in a Straight Line

The Foundation of Kinematics

Frame of Reference

Motion is always relative. An object can be at rest in one frame and in motion in another.

Distance vs. Displacement

Distance is a scalar quantity (total path), while displacement is a vector quantity (initial to final point).

Speed vs. Velocity

Speed is a scalar (distance/time), while velocity is a vector (displacement/time). Velocity also has direction.

Acceleration

The rate of change of velocity. It is a vector quantity, with SI unit m/s².

Kinematic Equations

These equations (v = u + at, etc.) apply to constant acceleration and describe motion.

Motion Under Gravity

This is a special case of constant acceleration (a = g ≈ 9.8 m/s²), which applies to free fall.

Rest, Motion & Frame of Reference

Basic Concepts

  • 🧘Rest
    • When an object does not change its position with respect to its surroundings over time.
    • Example: A book on a table, a clock on a wall.
  • 🏃Motion
    • When an object changes its position with respect to its surroundings over time.
    • Example: A moving car, a running athlete.
  • 🌐Frame of Reference
    • It is a coordinate system + a clock, relative to which we measure an object's position and motion.
    • Both motion and rest are relative. They depend on the observer's frame.

    Example: A passenger in a moving train is at rest relative to a fellow passenger, but in motion relative to a person standing on the platform.

  • 📍Point Object
    • If an object covers a distance much larger than its own size during its motion, it can be considered a point object.
    • This simplifies the analysis.

    Example: A car traveling between two cities, the Earth revolving around the Sun.

Types of Motion

Type Dimension Example
1D Motion One-Dimensional Car on a straight road
2D Motion Two-Dimensional Projectile, Carrom board
3D Motion Three-Dimensional Flying kite, Gas molecule

Dimensions of Motion

  • One-Dimensional (1D): Only one axis (e.g., x-axis) is needed to describe the motion. Also called Rectilinear Motion.
  • Two-Dimensional (2D): Two axes (e.g., x and y) are needed to describe the motion. The object moves on a plane.
  • Three-Dimensional (3D): All three axes (x, y, and z) are needed to describe the motion. The object moves in space.

Distance vs. Displacement

Key Definitions

  • 🛣️Distance
    • Definition: The total path length covered by an object.
    • Quantity: Scalar quantity. It has only magnitude, no direction.
    • Value: Always Positive. It can never be zero or negative (if the object is in motion).
    • Dependency: It depends on the path taken.
    • SI Unit: meter (m).
  • 🎯Displacement
    • Definition: The shortest, straight-line distance between the final position and the initial position.
    • Quantity: Vector quantity. It has both magnitude and direction.
    • Value: Can be Positive, Negative, or Zero.
    • Dependency: It only depends on the initial and final points, not the path.
    • SI Unit: meter (m).
The Golden Rule: The distance covered is always greater than or equal to the magnitude of the displacement.
Distance ≥ |Displacement|

Distance & Displacement: Examples

Numerical Examples

  • 🔄Case 1: Full Circular Path
    • An athlete completes one full circle of radius 'r'.
    • Distance: Total path length = Circumference of the circle.
      Distance = 2πr
    • Displacement: The athlete returns to the initial point (Final position = Initial position).
      Displacement = 0
  • 🌗Case 2: Half Circular Path
    • An athlete goes from A to B (diametrically opposite) on a path of radius 'r'.
    • Distance: Semi-circumference.
      Distance = πr
    • Displacement: Straight line from A to B = Diameter of the circle.
      Displacement = 2r
  • ➡️Case 3: Straight Line
    • A car goes from 0 to A (50m) and then returns from A to B (at 30m).
    • Distance: (0 to A) + (A to B) = 50m + (50-30)m = 50m + 20m.
      Distance = 70 m
    • Displacement: Final (B at 30m) - Initial (0m).
      Displacement = +30 m

Key Observations

  • Zero Displacement: Displacement can be zero, even if the distance is not (e.g., a full circle).
  • Negative Displacement: If the object ends up to the left of the origin (in 1D).
  • Equality: The magnitude of distance and displacement are equal only if the object moves in a straight line without changing direction.

The Golden Rule

Distance ≥ |Displacement|

PYQ Focus

Questions in exams often involve circular paths or back-and-forth motion on a straight line.

Remember: The Odometer measures distance, not displacement.

Speed

Definition & Properties

  • 🚄Definition: Speed
    • Concept: "How fast an object is moving."
    • Formal: The distance covered by an object per unit time.
    • Quantity: Scalar quantity. It has only magnitude, no direction.
    • Value: Always Positive or zero. It can never be negative.
  • 📐Formula
    • Speed = Distance / Time
    • v = s / t
  • ⏱️Units & Dimension
    • SI Unit: meter per second (m/s) or ms⁻¹
    • CGS Unit: centimeter per second (cm/s)
    • Other: kilometer per hour (km/h)
    • Dimensional Formula: [M⁰ L¹ T⁻¹]
Conversion: To convert km/h to m/s, multiply by 5/18.
Example: 36 km/h = 36 * (5/18) = 10 m/s.

Types of Speed

Different types of speed are used to describe motion:

  • Uniform Speed: The object covers equal distances in equal intervals of time.
  • Non-Uniform Speed: The object covers unequal distances in equal intervals of time. (e.g., car in traffic)
  • Average Speed: The average over the entire journey.
  • Instantaneous Speed: The speed at a specific instant.

Types of Speed

Detailed Classification

  • 🟰Uniform Speed
    • When an object covers equal distances in equal intervals of time, no matter how small the time intervals are.
    • In this case, Average Speed = Instantaneous Speed.
    • Graph (x-t): Is a straight line.
  • 📈Non-Uniform Speed
    • When an object covers unequal distances in equal intervals of time.
    • This happens when the speed is changing (increasing or decreasing).
    • Graph (x-t): Is a curve.
    • Example: Driving a car on a crowded street.
  • 📊Average Speed
    • The ratio of the total distance covered to the total time taken for the entire journey.
    • It tells how fast the object moved *on average*.
    • V_avg = Total Distance / Total Time
  • ⏱️Instantaneous Speed
    • The speed of an object at a particular instant of time or at a particular point on its path.
    • This is the speed that a speedometer shows.
    • Calculus: It is the derivative of distance with respect to time.
    • v = ds / dt (where Δt → 0)

Average Speed: Special Case

If an object covers half the distance with speed v₁ and the next half distance with speed v₂ (Distance is split):
V_avg = 2v₁v₂ / (v₁ + v₂)
(This is the Harmonic Mean)

Special Case 2

If an object travels for half the time with speed v₁ and the next half time with speed v₂ (Time is split):
V_avg = (v₁ + v₂) / 2
(This is the Arithmetic Mean)

Key Distinction

Average Speed is an 'overview' of the entire journey.

Instantaneous Speed is a 'snapshot' of a single instant.

Velocity

Definition & Properties

  • 🧭Definition: Velocity
    • Concept: "How fast and in which direction an object is moving."
    • Formal: The displacement of an object per unit time.
    • Quantity: Vector quantity. It has both magnitude + direction.
    • Value: Can be Positive (+), Negative (-), or Zero (0).
  • 📐Formula
    • Velocity = Displacement / Time
    • v⃗ = s⃗ / t (Vector notation)
  • ⏱️Units & Dimension
    • SI Unit: meter per second (m/s)
    • Dimensional Formula: [M⁰ L¹ T⁻¹]
    • (The units and dimensions for speed and velocity are the same)
  • ⚠️Key Distinction
    • The magnitude of velocity is speed.
    • Example: "50 km/h" is a speed. "50 km/h towards North" is a velocity.
    • If an object moves on a circular path at a uniform speed, its speed is constant, but its velocity is constantly changing (because the direction is changing).

Types of Velocity

Detailed Classification

  • 🟰Uniform Velocity
    • When an object covers equal displacement in equal intervals of time.
    • Condition: Both magnitude (speed) and direction must be constant.
    • Path: The object must move in a straight line.
    • Acceleration: In this state, acceleration is zero.
  • 📈Non-Uniform Velocity
    • If the velocity changes with time, it is called non-uniform velocity.
    • This can happen in 3 ways:
      1. Only speed (magnitude) changes, not direction (e.g., car accelerating on a straight road).
      2. Only direction changes, not speed (e.g., uniform circular motion).
      3. Both speed and direction change (e.g., car accelerating on a curve).
    • Whenever velocity is non-uniform, the object has acceleration.
  • 📊Average Velocity
    • The ratio of Total Displacement to Total Time.
    • V_avg = Total Displacement / Total Time
    • V_avg = (x₂ - x₁) / (t₂ - t₁) = Δx / Δt
  • ⏱️Instantaneous Velocity
    • The velocity of an object at a particular instant.
    • Calculus: It is the derivative of displacement with respect to time.
    • v = dx / dt (where Δt → 0)
    • The magnitude of instantaneous velocity is instantaneous speed.

Zero Average Velocity?

Yes! If an object returns to its starting point after a journey:

  • Total Displacement = 0
  • Average Velocity = 0
  • ...but Total Distance > 0, so Average Speed > 0.

Example: A full circular loop.

Average Velocity: Special Case

If an object moves with constant acceleration 'a' from 'u' to 'v':
V_avg = (u + v) / 2
(This is valid ONLY for constant acceleration)

🟰 Uniform (Constant V)
📈 Non-Uniform (Changing V)
📊 Average (Total Disp.)
⏱️ Instantaneous (dx/dt)

Acceleration

Definition & Properties

  • 🚀Definition: Acceleration
    • Concept: "How quickly the velocity is changing."
    • Formal: The rate of change of velocity.
    • Quantity: Vector quantity. Its direction is the same as the direction of the change in velocity (Δv).
  • 📐Formula
    • Acceleration = Change in Velocity / Time Taken
    • a⃗ = (v⃗ - u⃗) / t = Δv⃗ / Δt
    • (v⃗ = final velocity, u⃗ = initial velocity)
  • ⏱️Units & Dimension
    • SI Unit: meter per second squared (m/s²) or ms⁻²
    • Dimensional Formula: [M⁰ L¹ T⁻²]
  • 💡Cause of Acceleration
    • Acceleration occurs when velocity changes.
    • Velocity changes if:
      1. Speed changes.
      2. Direction changes.
      3. Both change.

    • Uniform circular motion is an accelerated motion because the direction is constantly changing (Centripetal Acceleration).

Types of Acceleration

Type Condition
Positive (+) Velocity is increasing
Negative (-) Velocity is decreasing
Zero (0) Constant Velocity

Retardation / Deceleration

Negative Acceleration is also called retardation or deceleration.
This occurs when the direction of acceleration is opposite to the direction of velocity, causing the object to slow down.
Example: Applying brakes.

Types of Acceleration

Detailed Classification

  • 🟰Uniform Acceleration
    • When the change in velocity is equal in equal intervals of time.
    • Both Magnitude and Direction remain constant.
    • Example: Motion under gravity (g ≈ 9.8 m/s²).
    • The Kinematic Equations are valid only in this condition.
  • 📈Non-Uniform Acceleration
    • When the change in velocity is unequal in equal intervals of time.
    • This happens if the magnitude or direction (or both) of acceleration is changing.
    • Example: A car's acceleration changing as it shifts gears.
    • Calculus is required to analyze this.
  • 📊Average Acceleration
    • The ratio of the total change in velocity to the total time interval.
    • a_avg = (v₂ - v₁) / (t₂ - t₁) = Δv / Δt
  • ⏱️Instantaneous Acceleration
    • The acceleration at a particular instant.
    • Calculus (1st Derivative): It is the derivative of velocity with respect to time.
    • a = dv / dt
    • Calculus (2nd Derivative): It is the second derivative of position with respect to time.
    • a = d²x / dt²

Calculus in Kinematics

This relationship is very important:

Integration

We can also go in reverse:

  • Velocity:
    v = ∫ a dt
  • Position:

Kinematic Equations - 1

The 3 Equations of Motion

CRITICAL ASSUMPTION:

These equations are valid ONLY when Acceleration ('a') is Constant.

  • 1️⃣First Equation: Velocity-Time Relation
    • Equation: v = u + at
    • Where:
      • v = Final Velocity
      • u = Initial Velocity
      • a = Constant Acceleration
      • t = Time
    • Derivation (Calculus): We know `a = dv/dt`. So, `dv = a dt`. Integrating both sides: `∫dv = ∫a dt` from u to v and 0 to t. This gives `[v] from u to v = a[t] from 0 to t` => `v - u = at` => `v = u + at`.
  • 2️⃣Second Equation: Position-Time Relation
    • Equation: s = ut + ½at²
    • Where:
      • s = Displacement
      • u = Initial Velocity
      • t = Time
      • a = Constant Acceleration
    • Derivation (Calculus): We know `v = dx/dt`. And `v = u + at`. So, `dx/dt = u + at`. `dx = (u + at)dt`. Integrating both sides: `∫dx = ∫(u + at)dt` from 0 to s and 0 to t. `[x] from 0 to s = [ut + at²/2] from 0 to t` => `s = ut + ½at²`.

Equation 1

v = u + at

Equation 2

s = ut + ½at²

Graphical Derivation (v-t graph)

These equations can also be derived from a v-t graph:

  • `v = u + at` comes from the Slope of the v-t graph.
    Slope = a = (v-u) / t
  • `s = ut + ½at²` comes from the Area under the v-t graph.
    Area = Area of Rectangle + Area of Triangle
    Area = (u * t) + (½ * (v-u) * t)
    ... (substitute v-u = at) ...
    Area = ut + ½(at)t = ut + ½at²
🔥 Constant 'a' ONLY
1️⃣ v = u + at
2️⃣ s = ut + ½at²

Kinematic Equations - 2

Remaining Equations

  • 3️⃣Third Equation: Velocity-Position Relation
    • Equation: v² = u² + 2as
    • Use: This is very useful when time ('t') is not known or not asked for.
    • Derivation: From Eq 1, `t = (v-u)/a`. Substitute this 't' into Eq 2, `s = u[(v-u)/a] + ½a[(v-u)/a]²`.
      `s = (uv - u²)/a + ½a(v² + u² - 2uv)/a²`
      `s = (uv - u²)/a + (v² + u² - 2uv)/2a`
      `2as = 2uv - 2u² + v² + u² - 2uv`
      `2as = v² - u²`
      `v² = u² + 2as`
  • 4️⃣Fourth Equation: Distance in nth second
    • Concept: Distance in 5th sec = (Total distance in 5s) - (Total distance in 4s).
    • Formula: sₙ = u + (a/2)(2n - 1)
    • Where: `sₙ` = Distance covered in the nth second.
    • Derivation:
      `sₙ = s(n) - s(n-1)`
      `sₙ = [un + ½an²] - [u(n-1) + ½a(n-1)²]`
      `sₙ = un + ½an² - [un - u + ½a(n² - 2n + 1)]`
      `sₙ = un + ½an² - un + u - ½an² + an - ½a`
      `sₙ = u + an - ½a`
      `sₙ = u + (a/2)(2n - 1)`

Equation 3

v² = u² + 2as

Equation 4 (nth second)

sₙ = u + (a/2)(2n - 1)

Motion Under Gravity

Free Fall

  • 🌎Definition: Free Fall
    • When an object moves solely under the influence of the Gravitational Force, it is called free fall.
    • Assumption: We consider Air Resistance to be negligible.
    • This is a perfect example of Uniform Acceleration.
  • 👇Acceleration due to Gravity (g)
    • The acceleration produced in an object due to Earth's gravity is called 'g'.
    • Value: `g ≈ 9.8 m/s²` (or `10 m/s²` for calculations)
    • Direction: Always Vertically Downwards, towards the center of the Earth.
    • The value of `g` does not depend on the object's mass, size, or density. (Galileo's Law)
  • 🔄Sign Convention
    • This is very important. We usually (Standard convention):
    • Take Upward motion as Positive (+).
    • Take Downward motion as Negative (-).
    • According to this convention, `a` is always `-g` (or `-9.8 m/s²`), because 'g' always acts downwards.
    • `u` (initial velocity) will be (+) if thrown up, (-) if thrown down.
    • `s` (displacement) will be (+) if above the origin, (-) if below it.
g ≈ 9.8 m/s² (Standard Gravity)

Galileo's Law of Fall

Galileo stated that in a vacuum, a feather and a hammer dropped from the same height will reach the ground at the same time.

  • This is because 'g' is the same for both and does not depend on mass.
  • (This was proven on the moon during the Apollo 15 mission!)

Alternate Convention

Sometimes, if the motion is only downwards (e.g., dropped from rest), Downward is taken as Positive (+) to simplify calculations.

In this case: `a = +g`, `u = 0`, `v` is (+), `s` is (+).

Consistency is key! (Stick to one convention)

Gravity: Equations & Cases

Equations for Free Fall

We substitute `a = -g` (using upward as positive) into the Kinematic Equations. `s` can also be represented by `h` (height).

Equation 1

v = u - gt

Equation 2

h = ut - ½gt²

Equation 3

v² = u² - 2gh

Equation 4 (nth)

hₙ = u - (g/2)(2n-1)

Special Cases

  • ⬇️Case 1: Dropped from Rest
    • Initial Velocity `u = 0`.
    • Equations (using `a = -g`):
      • `v = -gt`
      • `h = -½gt²`
      • `v² = -2gh`
    • (Note: v, h are negative, indicating downward motion)
  • ⬆️Case 2: Thrown Vertically Up
    • Initial Velocity `u` is Positive (+).
    • Acceleration `a = -g`.
    • At maximum height: `v = 0`.

Formulas for Upward Motion (Case 2)

  • Maximum Height (H):
    At top, v=0. Using `v² = u² - 2gh`:
    `0 = u² - 2gH`
    H = u² / 2g
  • Time of Ascent (tₐ):
    At top, v=0. Using `v = u - gt`:
    `0 = u - gtₐ`
    tₐ = u / g
  • Total Time of Flight (T):
    (Time up + Time down). `t_descent = t_ascent`.
    T = 2tₐ = 2u / g
Symmetry of Motion:

Ignoring air resistance, at any given height:

Speed going up = Speed coming down

⬇️ Dropped (u=0)
⬆️ Thrown Up (v=0 at top)
H = u²/2g
T = 2u/g

Position-Time (x-t) Graphs

Understanding x-t Graphs

  • 📈What is an x-t Graph?
    • It shows the change in an object's Position (x) with Time (t).
    • Time (t) is taken on the X-axis.
    • Position (x) is taken on the Y-axis.
  • ⛰️Slope of x-t Graph
    • The slope of an x-t graph gives Velocity (v).
    • Slope = Δx / Δt = Velocity (v)
    • Steeper slope: Higher velocity.
    • Flat slope (0 slope): Zero velocity (at rest).
    • Positive slope: Positive velocity.
    • Negative slope: Negative velocity.
    • Curved slope: Changing velocity = Acceleration.

Common x-t Graphs

  • 🛌Case 1: Object at Rest
    • The object's position does not change with time.
    • Graph: A straight line parallel to the Time-axis (X-axis).
    • Slope: 0.
    • Velocity: 0.
  • ➡️Case 2: Uniform Motion (v > 0)
    • The object is moving with constant velocity in the positive direction.
    • Graph: A straight line with a positive slope.
    • Slope: Constant & Positive.
    • Velocity: Constant & Positive.

    • Area above the time-axis = Positive displacement.
    • Area below the time-axis = Negative displacement.
    • Total Distance = Absolute sum of all areas.

Relative Velocity

Concept of Relative Velocity

  • 👓Definition
    • The velocity of one object (A) with respect to another moving object (B).
    • It measures how fast and in which direction A *appears* to move, as seen by B.
    • All velocities are actually relative to the Earth, which is our default 'stationary' frame.
  • 📐Formula (1D)
    • Velocity of A relative to B:
    • v_AB = v_A - v_B
    • Velocity of B relative to A:
    • v_BA = v_B - v_A
    • Note: v_AB = -v_BA (Same magnitude, opposite direction)

Special Cases (1D)

  • ➡️➡️Case 1: Same Direction
    • Two trains are moving in the same direction with `v_A` and `v_B`.
    • `v_A = +50` m/s, `v_B = +30` m/s
    • Relative velocity: `v_AB = v_A - v_B = 50 - 30 = +20` m/s.
    • (A appears to move 20 m/s faster than B).
    • Relative speed = `|v_A - v_B|`
  • ➡️⬅️Case 2: Opposite Direction
    • Two trains are moving towards each other with `v_A` and `v_B`.
    • `v_A = +50` m/s, `v_B = -30` m/s (opposite direction)
    • Relative velocity: `v_AB = v_A - v_B = 50 - (-30) = +80` m/s.
    • (They appear to approach each other at a faster speed of 80 m/s).
    • Relative speed = `v_A + v_B`

Real-life Applications

  • Overtaking: Time for one train to pass another `t = (L_A + L_B) / (v_A - v_B)` (same direction).
  • Crossing: Time for two trains to cross `t = (L_A + L_B) / (v_A + v_B)` (opposite direction).
  • Rain-Man Problems: At what angle to hold an umbrella to avoid rain (2D).
  • River-Boat Problems: Shortest path or shortest time to cross a river (2D).
Mental Trick:

To find `v_AB`, 'stop' `v_B` (treat it as 0) and add the same `(-v_B)` velocity to `v_A`.

v_AB = v_A + (-v_B)
